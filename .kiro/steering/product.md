# Product Strategy & Principles

## Vision
Build reliable, high-performance audio software, testing harnesses, and karaoke synchronization applications through Spec-Driven Development (SDD) executed by autonomous AI agents with zero hallucinations, zero infinite loops, and deterministic quality gates.

## Core Directives
1. **Spec-Driven Autonomy:** Code is never written without an approved specification (`requirements.md` -> `design.md` -> `tasks.md`).
2. **Quality Before Speed:** Every line of code is guarded by Test-Driven Development (TDD) and verified by fresh execution evidence.
3. **Auditability:** Every subagent action, test outcome, and gate transition produces structured, machine-readable telemetry for automation testing teams.
4. **Zero Regressions:** Continuous watchdog monitoring prevents silent failures, loops, or scope creep.
