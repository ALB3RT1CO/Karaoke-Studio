## Technical Recommendation & Action Plan

### 1. The Strategy: Two-Stage Verification
1. **Curated Catalog Table (This Document)**: Maintain this table as the authoritative mapping index.
2. **Metadata Injection into In-Memory Store**: Update `src/server/server.ts` to load this curated catalog so each song automatically possesses its correct Author, clean title, and exact YouTube video ID.
3. **Interactive "Edit YouTube Link" on the Web UI**:
   - Add a pencil icon or "Change Video" button on the web player.
   - If you ever prefer a different backing track (e.g. higher key, lower key, male/female pitch, or official acoustic), you can paste any YouTube URL directly into the player.
   - The app parses the `v=` parameter, updates the song in RAM, and appends the transaction to `data.jsonl`.
